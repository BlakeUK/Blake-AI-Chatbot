Only checks pages on blake-uk.com / www.blake-uk.com. Soft-404, duplicate-content and JS-dependency flags are heuristics for a human to spot-check, not a definite verdict — see the notes in each row. Built for Blake UK internal QA use.

This is an on-page/technical/crawlability audit, not a replacement for Semrush or Ahrefs: it has no backlink index, keyword/ranking data, traffic estimates, or a Core Web Vitals/Lighthouse renderer, since those all require proprietary crawled datasets or paid APIs this tool doesn't have access to. What it does check — status/redirects, on-page SEO, structured data, and bot/AI crawler access — is everything achievable from a single server-side fetch per page.
